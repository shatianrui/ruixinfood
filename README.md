# 睿鑫食品网站

当前网站：https://ruixinfood.top/

`dist/` 保存当前线上网站的完整 HTML、CSS、JavaScript 和图片资源。`vercel.json` 将 Vercel 发布目录设置为 `dist`。

## 本地运行

需要 Node.js，无需安装依赖。运行 `npm start`，打开 http://127.0.0.1:4173 。使用 `npm run check` 检查 JavaScript 语法。
